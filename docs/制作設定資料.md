# DINO ESCAPE — 火山から逃げろ！ 制作設定資料

## 決定事項（2026-10-08）

- フォルダ・リポジトリ名: `dino-escape`（公開予定 URL: https://fish-suika.github.io/dino-escape/）
- 対象: PC ブラウザ（キーボード操作のみ）。スマホ対応は資料どおり対象外（必要になったら後で検討）
- 画面: 横長の全画面（資料にPC対象とあるため。縦 9:16 枠は使わない）
- 作り方: これまでと同じく three.js（r128）＋ `src/` を `build.sh` で1枚の HTML に結合。外部素材ファイルなし、音は WebAudio で生成
- 進め方: Phase 1〜8 を順に。各 Phase の終わりに本人が遊んで OK を出してから次へ
- 安全地帯までの距離（クリア距離）は資料に数値がないため、1プレイ1〜3分に収まるよう Phase 6 で決める

---

## 1. ゲーム概要

### コンセプト
プレイヤーは恐竜になり、突然噴火した火山から逃げ続ける。
上空から大量の噴石が降ってきたり、背後からマグマが迫ってきたりする中を走り、安全な場所まで逃げ切るゲーム。

ゲームの目的は非常にシンプル。
「とにかく火山から逃げろ！」

難しい謎解きや複雑なシステムは入れない。
「走る」「避ける」「ジャンプする」という基本操作だけで遊べる、短時間で楽しめるブラウザゲームにする。

## 2. ゲームジャンル

* 3Dアクション
* サバイバル
* シンプルゲーム
* バカゲー寄り
* 1プレイ数分程度

## 3. 技術方針

* HTML
* CSS
* JavaScript
* Three.js
* 外部素材ファイルなし
* 3DモデルはThree.jsの基本Geometryを中心に構築
* ブラウザだけで動作する
* PCブラウザを基本対象とする

恐竜も敵も地形も、基本的にはThree.jsで生成する。
見た目はシンプルでも、動きやエフェクトを派手にして「ゲームとしての気持ちよさ」を出す。

## 4. プレイヤー

### 恐竜
プレイヤーは一匹の恐竜。
恐竜の種類は最初は1種類だけでよい。
見た目はリアルすぎなくてよい。
むしろ少しコミカルな3D恐竜にする。

### 基本性能

* 常に前方向へ走る
* 左右移動可能
* ジャンプ可能
* 空中で多少方向修正可能
* 移動速度は一定
* 時間経過によって少しずつスピードアップしてもよい

## 5. 操作（PC）

移動

* A / ←：左
* D / →：右

ジャンプ

* Space：ジャンプ

リスタート

* R：ゲームオーバー後に再スタート

マウス操作は基本的に使用しない。

## 6. カメラ

三人称視点。
恐竜の後方から見下ろすようなカメラにする。

```text
        火山
         🌋
          ↓
      🪨 🪨 🪨

       ───────
          🦖
          ↓
      カメラ
```

恐竜は画面中央付近。
進行方向が常に分かるようにする。
カメラは恐竜の動きに滑らかについてくる。
激しいカメラ回転は避ける。

## 7. ステージ

一本道を基本とする。
プレイヤーは火山から離れる方向へ進み続ける。
道路のような明確な一本道ではなく、
「荒野を走って逃げている」
ような見た目にする。

### 地形

* 火山灰で覆われた地面
* 岩
* 小さな丘
* 大きな岩
* 焼けた木
* クレーター
* 溶岩の川

などを配置する。
ただし、最初から障害物を増やしすぎない。

## 8. 火山

ステージ後方に巨大な火山を配置する。
ゲーム開始時は火山が少し煙を出している。
ゲーム開始から数秒後、
「ドゴォォォン！！！」
という大きな噴火が発生する。

火山から、

* 黒煙
* 火
* 火山灰
* 噴石

が大量に噴き出す。
火山はゲーム中ずっと噴火し続ける。

## 9. 噴石システム

このゲームのメイン要素。
火山から大量の噴石が飛んでくる。

### 噴石の動き
噴石は空高く飛び、
プレイヤー周辺にランダムに落下する。
落下地点には事前に
「危険マーカー」
を表示する。

```text
       🪨
       ↓

      ⭕
     危険！

       🦖
```

円形の赤い警告範囲を表示。
プレイヤーは、
「そこに落ちてくる！」
と見てから避けられるようにする。

## 10. 噴石の危険度

噴石には大きさの違いを作る。

小型

* 小さい
* 落下速度が速い
* ダメージ小

中型

* 普通の大きさ
* ダメージ中
* 少し吹き飛ばす

大型

* 非常に大きい
* 落下前の警告範囲も大きい
* 直撃すると恐竜が大きく吹っ飛ぶ

大型噴石は、画面に巨大な影が入ってくる演出を入れると迫力が出る。

## 11. 噴石の直撃

噴石に当たると即死ではなく、
恐竜が大きく吹き飛ばされる。
ここはゲームの見せ場。

```text
🪨
 ↓

💥🦖━━━━━━→

       「ギャーー！！」
```

恐竜が回転しながら吹っ飛び、地面を転がる。
その後、

* 少し立ち上がる
* 移動速度が一時的に低下
* 再び逃走

という流れ。
ただし、巨大噴石の直撃など、一部の攻撃は即ゲームオーバーでもよい。

## 12. マグマ

噴石と並ぶもう一つのメイン要素。
火山から流れ出したマグマが、ステージの後方から徐々に迫ってくる。
画面の後ろから、
「ゴゴゴゴゴ……」
という音とともにマグマが迫る。
プレイヤーが立ち止まっているとマグマに追いつかれる。

## 13. マグマの特徴

マグマは単純に後ろから迫ってくるだけでよい。
複雑なAIは不要。
時間経過で速度を上げる。

序盤：マグマは遅い。
↓
中盤：少しずつ速度が上がる。
↓
終盤：かなり速くなる。

プレイヤーに
「もう少しで追いつかれる！」
という緊張感を与える。

## 14. マグマに触れた場合

マグマに触れたらゲームオーバー。
恐竜がマグマに飲み込まれる演出を入れる。
画面に、
GAME OVER
を表示。
その下に、
火山から逃げ切れなかった……
と表示する。

## 15. ステージ上の障害物

障害物は少しずつ追加する。

- 岩：普通に置かれている岩。ジャンプして避ける。
- 焼けた木：倒木として配置。ジャンプして越える。
- クレーター：小さな穴。大きすぎないようにする。
- マグマ溜まり：進行方向に小さなマグマがある。左右に避ける。

## 16. 障害物と噴石の組み合わせ

ゲーム後半では、
地面の障害物＋噴石
を組み合わせる。

```text
          🪨
          ↓
       ⭕⭕⭕

      █ 岩 █

        🦖
```

岩をジャンプしようとした瞬間に噴石が落ちてくるなど、
プレイヤーに瞬間的な判断を要求する。
ただし、理不尽な配置にはしない。
必ず回避可能なルートを作る。

## 17. 難易度上昇

時間経過で徐々に難しくする。

0～20秒：チュートリアル的な難易度。

* 噴石少ない
* マグマ遅い
* 障害物少ない

20～40秒：通常難易度。

* 噴石増加
* 岩が増える
* マグマ速度上昇

40～60秒：危険ゾーン。

* 噴石大量
* 大型噴石登場
* 障害物増加
* マグマ高速化

60秒以降：最終逃走。
火山の噴火が最大になる。
画面全体が揺れ、
噴石が大量に降ってくる。

## 18. クリア条件

一定距離を走ると、
安全地帯
に到着する。
例：
大きな岩山の裏側や洞窟。

恐竜が安全地帯に入ると、
火山の音が小さくなり、
恐竜が後ろを振り返る。
その後、
火山がさらに大爆発する。
CLEAR
を表示。

## 19. クリア演出

クリアした瞬間に、
恐竜が安全地帯で息を切らす。
その後ろで、
ドゴォォォォォン！！！
と火山が大噴火。
恐竜が驚いて振り返る。
少し間を置いて、
恐竜が
「……危なかった」
と言いたげなリアクションをする。
セリフを入れる場合は文字だけでもよい。

## 20. スコア

スコアはシンプルにする。

基本スコア：走った距離

追加ボーナス：

* 噴石をギリギリで回避
* 大型噴石を回避
* 障害物を連続回避
* マグマとの距離が近い状態で走り続ける

など。
ただしスコアシステムはゲームの中心ではない。

## 21. 「ギリギリ回避」演出

プレイヤーが噴石の危険範囲ギリギリを通過した場合、
画面に一瞬、
GREAT ESCAPE!
のような表示を出す。
同時に小さな演出を入れる。
これによって、
「ギリギリで避けるのが気持ちいい」
ゲームにする。

## 22. サウンド・演出

重要。
ゲーム自体はシンプルなので、
音と画面演出で迫力を出す。

火山

* ゴゴゴゴ……
* 爆発音
* 噴火音

噴石

* ヒュゥゥゥ……
* ドゴン！

マグマ

* ジュワジュワ
* ゴゴゴ……

ダメージ

* ドン！
* 恐竜の鳴き声

## 23. 画面揺れ

大型噴石が落下したとき、
火山が大噴火したとき、
マグマが近づいたときなどに、
短時間だけカメラを揺らす。
ただし揺れすぎて操作不能にならないようにする。

## 24. UI

画面上部に最低限の情報だけ表示。

```text
距離：1250m

🔥 危険度：HIGH
```

ゲーム中に大量のUIを表示しない。
画面を見て、

* 恐竜
* 火山
* 噴石
* マグマ

がすぐ分かることを優先する。

## 25. ゲームオーバー

死亡理由によって少しだけ演出を変える。

- マグマに飲まれた：恐竜が逃げながら画面下へ消えていく。
- 噴石直撃：恐竜が派手に吹き飛ぶ。
- 障害物衝突：恐竜が転倒する。

その後、

```text
GAME OVER

逃走距離：XXXXm

[R] もう一度逃げる
```

## 26. ゲーム全体のテンポ

1プレイは長くしすぎない。
目安：1～3分程度
短時間で、
「もう一回やってみよう」
と思えるゲームにする。

## 27. 最重要コンセプト

このゲームでは、
「操作を複雑にする」のではなく「状況をどんどん面白くする」
ことを重視する。

プレイヤーの操作は、

* 左
* 右
* ジャンプ

だけ。
しかしゲーム中には、

* 噴石が飛んでくる
* マグマが迫ってくる
* 岩がある
* 火山が爆発する
* 大型噴石が落ちてくる
* 地面がマグマになる

など、次々と危険が発生する。
プレイヤーは、
「次は何が来る！？」
という状態で逃げ続ける。

## 28. ゲームの面白さ

このゲームの面白さは、
「迫ってくる危険からギリギリで逃げる」
こと。

特に、
噴石の警告を見る → 「ヤバい！」 → 横に移動 → 目の前に岩 → ジャンプ → 着地した瞬間に後ろからマグマ → 全力で逃げる
というような、
短い時間の中で状況が連続して変化するゲームプレイ
を目指す。

## 30. Claudeへの実装方針

この設定資料を基準として実装する。
実装前に、必要な作業をフェーズごとに整理する。
一度にすべてを実装せず、
設計 → 実装 → 動作確認 → 問題修正
の順番で進める。
ただし、細かい問題を1個ずつ何度も修正するのではなく、
動作確認で見つかった問題をまとめて整理してから修正する。
各フェーズが完成したら、そのフェーズの完成状態を確認してから次のフェーズへ進む。
ゲームとして実際に遊んだときの、
「逃げていて楽しいか」
を最優先にする。

## 完成イメージ

恐竜になって火山から逃げる → 火山が噴火 → 恐竜が走り出す → 噴石が落ちてくる → 避ける → 岩が出てくる → ジャンプ → 後ろを見る → マグマがめちゃくちゃ迫っている → 「ヤバい！！」 → さらに走る → 大型噴石が目の前に落下 → ギリギリ回避 → 安全地帯へ到着 → 背後で火山が大爆発 → CLEAR！

## 一番大事なこと

このゲームはリアルな火山シミュレーターを作るゲームではない。
「恐竜が火山から必死に逃げる」という、
見た瞬間にルールが分かって、プレイするとハチャメチャになるゲーム
を目指す。
