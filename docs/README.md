# DINO ESCAPE — 火山から逃げろ！

恐竜になって、突然噴火した火山から逃げ切るブラウザゲームです。走る・避ける・ジャンプするだけ。1 プレイは約 2 分。

## 遊び方

- 後ろから迫ってくるマグマに追いつかれたらゲームオーバーです。
- 空から噴石が降ってきます。落ちる場所には赤い危険マーカーが出るので、見てから避けましょう。直撃しても即死ではなく、吹き飛ばされて少し遅くなります。
- 道は 3 レーン。岩・倒木・クレーターはジャンプで越え、マグマ溜まりは隣のレーンへよけ、頭上の木や岩のアーチは「くぐる」（スライド）で通ります。
- 走った距離が 2200m に届くと、安全な洞窟に逃げ込んでクリアです。そのあと火山が大爆発します。

## 操作（PC のキーボード）

| キー | 動き |
| --- | --- |
| ← → / A D | 隣のレーンへ移動（1 回押すと 1 レーン。押しっぱなしでは動かない） |
| ↓ / S | くぐる（スライド。空中で押すと急降下して、着地してすぐ滑る） |
| Space | ジャンプ（タイトルではスタート、クリア演出中は結果画面へスキップ） |
| M | 音の ON / OFF |
| R | もう一度逃げる（GAME OVER、またはクリアの結果画面で） |

## スコア

基本のスコアは走った距離（m）です。次のボーナスが加わります。画面左上の「SCORE」の下に「+100」のように出ます。

| ボーナス | 点数 |
| --- | --- |
| 噴石をギリギリで回避（着弾点から、着弾半径＋恐竜の半径の 1.0〜1.8 倍の距離で被弾せず通過）→「GREAT ESCAPE!」 | +100（大型は +300、「BIG ESCAPE!!」） |
| 大型噴石の警告円の中にいたのに、着弾までに外へ逃げ切った | +300 |
| 障害物を 3 連続以上で回避（被弾・転倒で連続数がリセット） | +50 × 連続数（連続数は 10 まで） |
| マグマとの距離が 20m 以内の状態で走り続ける | 1 秒ごとに +40 |

- 1 つの噴石・1 つの障害物で加点されるのは 1 回だけです。直撃した噴石、ぶつかった障害物は加点なしです。
- ベストスコアはブラウザの localStorage（キー `dino-escape-best`）に保存されます。保存できない環境（file:// で開いた場合の一部のブラウザ、プライベートモードなど）でも動作し、その場合はそのセッションの間だけベストを覚えます。

## 調整値

数値はすべて `src/10-config.js` の `CFG` にあります。スコアは `CFG.score`、クリア演出の秒数・洞窟の大きさは `CFG.clear`、タイトル画面のカメラは `CFG.title` / `CFG.orbit` です。

## ビルド

分割したソース（`src/`）を 1 枚の HTML に結合します。外部素材ファイルはなく、音は WebAudio で生成しています（three.js r128 だけ CDN から読み込みます）。

```sh
sh build.sh
```

`dino-escape.html`（本体）、`index.html`（同じ内容。GitHub Pages 用）、`verify.html`（検証ページ）ができます。

## 検証

`verify.html` をブラウザで開くと、純ロジック（物理・噴石・マグマ・障害物・難易度・スコア・タイトルとリスタートの流れ・クリア演出の状態機械・ベストスコア・自動プレイのボット評価）のテストが走ります。最後に `ALL PASS (件数)` と出れば成功です。ボット評価に約 1 分かかります。

`file://` で開くと、ブラウザによっては再読み込みしても古い内容のままになることがあります。開発中は簡単な HTTP サーバー経由で開いてください。

```sh
python -m http.server 8124   # ここで http://localhost:8124/dino-escape.html を開く
```

開発用に `window.GAME` が公開されています（`GAME.step(1/60)` で 1 フレーム進める、`GAME.start()` でタイトルから開始、`GAME.restart()` など）。

## 既知の注意点

- 対象は PC ブラウザ（キーボード操作のみ）です。スマホ・タッチ操作には対応していません。
- 音は最初のキー入力（Space など）のあとに鳴り始めます（ブラウザの自動再生の制限のため）。
- タブが非アクティブになると描画が止まります。戻ったときは 1 フレームの経過時間に上限（0.05 秒）があるので、ゲームが飛ぶことはありません。

## 改修 A（テストプレイ後）の変更点
- 3 レーン制（`CFG.lane`）：左右キーは押した瞬間だけ有効で 1 レーン。移動は約 0.13 秒でなめらかに補間し、移動中の入力は 0.15 秒覚えて順に実行する。障害物・噴石の落下地点もレーン単位。
- くぐる（`CFG.slide`、S / ↓）：滑走 0.7 秒。頭上の障害物「アーチ」（`CFG.obstacle.arch`、距離 90 から）は、立ったままだと当たり、ジャンプでは越えられず、スライドなら通れる。
- マグマが近いときは溶岩の高さを低くして（`CFG.magma.view`）恐竜が隠れないようにした。死亡時だけ従来どおり覆う。
- 噴石の直撃後の減速を緩和（`CFG.rock.sizes[*].slowSec / slowF`）。難易度は magma 速度・噴石の狙い率・rubberMin を軽く補正して維持した。
